# Atoms Demo · AI 应用生成工作区

用一句话描述想要的应用，智能体自动生成，右侧马上可以使用。单个 `index.html` 文件，不用安装任何东西。

## 快速开始

1. 在 [智谱开放平台](https://open.bigmodel.cn/) 注册，创建一个 API Key。
2. 打开 `index.html`，把顶部这一行改成你的 Key：
   ```js
   const ZHIPU_API_KEY = '你的Key';
   ```
3. 双击 `index.html` 用浏览器打开就能用。

## 界面

| 区域 | 作用 |
|------|------|
| 左栏 · 我的应用 | 切换应用；鼠标悬停后点 ✕ 删除（会连同对话和数据一起删除） |
| 中栏 · Atoms 工作区 | 用来**创建和修改应用**，不直接回答问题 |
| 右栏 · 预览 | 生成好的应用，在这里输入内容、获取结果 |

## 怎么用

**第一步：在中栏创建应用**

| 你说 | 生成 |
|------|------|
| 做一个 AI 写作助手 | 输入主题，生成文章 |
| 做一个 AI 代码助手 | 输入需求，生成代码（Dockerfile、nginx 配置等） |
| 做一个 AI 问答助手 | 多轮对话 |
| 自由描述，如「做一个管理读书笔记的应用」 | 由 AI 判断该用哪种应用（需 3–8 秒） |

**第二步：在中栏继续修改**

- 换主题：「换个紫色主题」（支持红、蓝、紫、绿、橙、粉）
- 加功能：「加一个导出功能」，应用右上角会出现「⬇ 导出」按钮

**第三步：在右栏使用应用**

在应用的输入框里输入内容，按回车或点「生成」/「发送」。

> 💡 常见误区：在中栏输入「写一个 nginx 配置文件」不会得到配置内容。应该先在中栏创建「AI 代码助手」，再到**右栏**输入这个需求。

## 数据保存

应用、对话和生成的内容都保存在当前浏览器里（IndexedDB），刷新页面不会丢失。换浏览器或清除网站数据后会清空。

## 部署到 GitHub Pages

1. 把 `index.html` 上传到 GitHub 仓库根目录。
2. 进入仓库 **Settings → Pages**，Source 选 `main` / `(root)`，点 Save。
3. 等 1–2 分钟后访问 `https://用户名.github.io/仓库名/`。

> ⚠️ Key 写在网页代码里，部署后任何人都能看到。建议在智谱后台给 Key 设置用量上限，并定期更换。

## 常见问题

| 提示 | 处理 |
|------|------|
| 请先把 ZHIPU_API_KEY 替换为… | 还没填 Key，或 Key 里混进了中文、空格 |
| API 错误 401 | Key 无效或已过期，换一个新的 |
| 请求超时，请重试 | 网络较慢，超过 20 秒，再发一次即可 |
| 我没太理解这个需求 | 改成「做一个 XX 助手」这种说法 |
